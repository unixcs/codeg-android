## 批v144：真机堆栈定位闪退 + 「提交结果未知」实测根因 + 派发默认选项 + 三列滚轮选择器（2026-11-01）

## 批v149.2：上传图片/文件失败与「重试永久失败」修复（2026-11-02）
- 背景：主人报「1MB 多的图片提示文件过大上传失败，之后图片/文件（哪怕几 KB）全部失败，在当前对话窗口重试仍失败」。
